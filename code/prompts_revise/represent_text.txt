PROSE READING
Read the supplied prose, headings, captions, and footnotes in context. Distinguish the present study's hypotheses and results from findings attributed to previous studies. Resolve grammatical direction, pronouns, abbreviations, and hypothesis references only when the supplied text or shared context establishes their meaning.
Bind each reported estimate and significance statement to its directed endpoints, roles, and estimation context. Do not attach a neighboring number to a relation simply because both occur in the same paragraph. Distinguish an explicit indirect or interaction effect from a narrative about its component direct paths. Do not interpret a supported/rejected hypothesis as a significance statement by itself.
If the input is a subset or a single paragraph, extract what it supports; an unmentioned path is not absent from the article. Shared context resolves identities and scopes but cannot provide a missing path or estimate. Apply TABLE READING only when table content is actually supplied.
