TABLE READING — SHARED BY HTML TABLES AND TABLE IMAGES
Read the entire supplied table with its title, caption, row and column labels, panel labels, and footnotes. HTML structure and a table image are alternative representations of the same table. If both are supplied, they do not count as independent agreement; use the readable original image to resolve an evident conversion error. Do not invent missing or unreadable cells.
Resolve multilevel headers, merged cells, rowspans/colspans, and repeated header blocks before assigning a cell. Identify the outcome, predictor, mediator/moderator, model, group, and coefficient/test column for each eligible record. Neither row position nor column position alone defines direction; obtain predictor/outcome roles from the actual headers, labels, and caption. Resolve abbreviated or implicit endpoints only through explicit table scope and the shared context.
Separate standardized coefficients, unstandardized coefficients, standard errors, t/z statistics, p-values, confidence bounds, relative effects, and sample sizes. A confidence bound, test statistic, percentage, or standard error is not beta. Do not slide values across adjacent model/group columns, rows, or panels. A blank cell or dash is missing information unless the table explicitly defines it otherwise; it is not zero or nonsignificance.
Distinguish structural estimates and explicit hypothesis paths from correlations, descriptive statistics, factor loadings, reliability measures, and fit indices. Include eligible control paths and nonsignificant estimates. For rows labeled direct, indirect, or mediating effect, use the caption and scope to identify the directed endpoints and named single mediator. Exclude total effects and serial mediation; do not compute indirect effects from component coefficients.
Read superscripts and footnotes with their exact scope. A significance legend applies only to the cells or panel it governs. A scoped legend supplies a reported p bound for each cell carrying its symbol: a stated bound as written (e.g. "* p<0.05" → "<0.05"), "significant at α" as p="<α"; apply the shared significance rule without assuming alpha. Missing stars alone do not imply nonsignificance. Retain explicit hypotheses with null unreported statistics.
For table images, transcribe only readable labels and cells into the required fields; no separate OCR or figure transcription is supplied in extraction/review stages. For HTML tables, preserve the semantic header hierarchy rather than reading flattened text as a sequence of numbers.
