TEXT REVIEW INPUT
Review the candidates against the supplied original prose using PROSE READING and the common review contract. In the text-with-HTML condition, also use TABLE READING for supplied HTML tables; in the text-without-tables condition, no table bodies are available. Figure images and figure transcriptions are not inputs to this review.
Optional ARTICLE COEFFICIENT CHECKS are search aids. possible_omissions flags detected coefficient assignments whose values were not found among candidates; inspect their actual endpoints, roles, estimate, and context before adding or replacing a relation. Duplicates and ineligible statistics need no addition. coefficients_not_in_article flags values not detected in the supplied text; this is not proof that an inherited record is false.
Numeric checks may round values and different paths may share values. These diagnostics cannot establish path identity, verify significance, or detect every omission, especially in tables or paths with no beta. Review the original material for semantic errors and missing eligible relations even when no diagnostic flags are supplied. Do not edit merely to clear a flag. Return only the common revision decision object.
